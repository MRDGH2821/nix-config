# Numtide Blueprint Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate the homelab Nix flake configuration to `numtide/blueprint` architecture using `prefix = "nix"`.

**Architecture:** `flake.nix` delegates output generation to `inputs.blueprint.lib.flake { inherit inputs; prefix = "nix"; }`. Blueprint automatically discovers host configurations from `nix/hosts/`, NixOS modules from `nix/modules/nixos/`, custom library functions from `nix/lib/default.nix`, devshell from `nix/devshell.nix`, formatter from `nix/formatter.nix`, and checks from `nix/checks/`.

**Tech Stack:** Nix, Flakes, Numtide Blueprint, NixOS, Home Manager, treefmt, pre-commit-hooks, just.
